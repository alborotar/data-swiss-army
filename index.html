FAQ

Is my data uploaded anywhere?

No. Every conversion runs in JavaScript inside your browser tab. You can disconnect from the internet and it keeps working.

How large a file can it handle?

Tens of MB comfortably on a modern laptop; the limit is your browser's memory.

Does it handle nested JSON?

Nested objects/arrays are serialized as JSON strings inside CSV, Markdown and SQL cells so nothing is lost.
